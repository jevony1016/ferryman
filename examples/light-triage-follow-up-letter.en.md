# Example: when first principles is not worth it (Light, English conversation)

> **Illustrative example.** Shows Step 1 triage ending the analysis early. Fictional scenario.

---

**User**: Use first principles: should I write my monitoring visit follow-up letter from scratch, or use the template my team uses?

**Assistant**:

I read this as: choosing between your team's template and a self-written follow-up letter for one visit. Depth level: **Light**. Tell me if that's wrong.

One question first, because it could change the answer: **has the template caused a problem before**, such as missed action items, a complaint from the investigator site, or an audit finding?

**User**: No, it's fine. I just wondered if starting from scratch would be better.

**Assistant**:

**One-line conclusion**: Use the template. This decision doesn't need first-principles analysis.

**Why**: Every triage condition points the same way.
- Low impact.
- Easily corrected: a letter can be amended or followed up.
- The current approach works.
- The team relies on a consistent format.

Rebuilding from scratch would cost time without changing anything that matters.

**What would change this**: if the template keeps producing the same problem, such as action items that investigator sites misread or that slip past their deadline. That would be a recurring failure, and worth breaking down: what the letter is for, what the investigator site actually needs from it, and which template sections serve that.

**Your call**: if you want to improve the template anyway, note down one concrete annoyance each time you use it. After a few visits you'll know whether there's a real pattern.
