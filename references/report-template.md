# Report template (Step 6)

Write all section names and content in the user's language. Scale to the depth level: a Light decision may need only the first three sections; a Deep one uses all of them. Use tables only where they make comparison easier; keep tables to 4 columns or fewer so they read on a phone.

```markdown
## One-line conclusion
[The answer in one sentence, conditional on the user's priorities if values decide it.]

## The question, as understood
[1–2 sentences.] Depth level: Light / Standard / Deep.

## Act now (only if needed)
[Anything that must happen before the analysis: safety, a deadline about to pass.]

## Is first-principles analysis worth it here?
[Triage result and why. If not worth it: experience-based recommendation, then stop.]

## Rules in play
| Rule | Source (jurisdiction, version, article) | Exact wording |
|---|---|---|
| ... | e.g. employment contract §7 / company policy v2 / China GCP 2026, Art. 26 / protocol v3.0 §8.2 | "verbatim quote" (+ translation if needed) |

## Breaking it down
Method(s) used: [repeated why / cost breakdown / assumption audit / analogy removal], and why.

| Premise | Source | Keep? |
|---|---|---|
| ... | rule / fact / experience / consensus / authority / guess | keep / check / drop |

Base facts reached:
- ...

## Options
For each option: what it is · which base facts it follows from · what it changes or drops · what it costs.

## Experience brought back
Keep: ... / Modify: ... / Drop: ...

## Verification
- Reasoning chain: base fact → ... → option
- Strongest opposing argument: ...
- Failure conditions (what would show this is wrong): ...
- Smallest test (cheap, reversible): ...
- Still unknown (treated as assumptions): ...

## Review log
- What the adversarial review changed: ...
- What is still disputed: ...

## Your call
If you care more about [A], [option] fits. If [B] matters more, [option]. [Anything only the user can know.]
```

## Style

- Plain words. Explain any term the user may not know the first time it appears.
- Short paragraphs; readable on a phone.
- Say "I don't know" where you don't.
- No flattery, no motivational filler.
