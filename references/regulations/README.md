# Regulation and guideline texts

Verbatim texts from official sources. Each file starts with its source link, version, dates, and conversion notes. **The official published versions prevail.** Quote from these files; never reconstruct regulation wording from memory. If a needed text is not here, say "not verified in this repository" and point the user to the official source.

Check the version that applied **on the date of the event**. China's 2026 GCP took effect on 2026-09-01 and replaced the 2020 version (NMPA 2020 No. 57), which is not included here. For the CDE Chinese versions of ICH guidelines, the NMPA notice that made each guideline apply in China, and from when, is quoted in the file header.

## Sources and reuse

As stated in the file headers:

- **China texts**: official publications; each header gives the official link and says “原文照录，以官方发布为准”.
- **ICH (English and CDE Chinese)**: copyright ICH. The ICH notice allows reuse provided ICH's copyright is acknowledged, changes are clearly labelled, and no impression of ICH endorsement is given. Each file labels its changes and states that the conversion is not endorsed by ICH (Chinese files: not endorsed by ICH or CDE).
- **CTCAE (NCI)**: the CTCAE files carry no copyright or licence statement. The NCI page that lists them says (verbatim): "In the case of permitted digital reproduction, please credit the National Cancer Institute as the source and link to the original NCI product using the original product's title". When quoting CTCAE, give the credit line in the file header, for example: "Common Terminology Criteria for Adverse Events (CTCAE) v6.0 (MedDRA 28.0)" was originally published by the National Cancer Institute: https://dctd.cancer.gov/research/ctep-trials/trial-development/ctcae-v6.0.xlsx. NCI states no MedDRA licensing condition on its CTCAE pages or files.
- **eCFR**: eCFR is an editorial compilation; the official legal edition is the annual CFR / Federal Register.
- **EUR-Lex**: "Source: EUR-Lex, https://eur-lex.europa.eu, © European Union, 1998–2026. Reuse is authorised under Commission Decision 2011/833/EU … provided the source is acknowledged." The consolidated text "has no legal effect"; only the Official Journal is authentic.
